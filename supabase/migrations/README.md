# Migraciones Supabase — LIREP

Las migraciones se aplicarán al proyecto Supabase independiente de LIREP.

Reglas:
1. No modificar migraciones ya aplicadas.
2. Toda evolución crea una migración nueva.
3. RLS obligatorio para datos multiempresa.
4. Reclamos y auditoría no tendrán borrado ordinario desde clientes.
5. La versión legal aplicable se conservará con cada expediente.
